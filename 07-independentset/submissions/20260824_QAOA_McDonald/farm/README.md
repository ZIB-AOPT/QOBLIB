# QAOA Submission for farm.gph

This submission solves the Maximum Independent Set problem for the `farm.gph` instance using the Quantum Approximate Optimization Algorithm (QAOA).

## Methodology
- **Algorithm**: QAOA
- **Depth**: p=3
- **Optimizer**: COBYLA
- **Simulator**: AerSimulator
- **Platform**: The Structure (Autonomous AI Orchestration)

The optimization was performed with warm-starting from p=1 to p=3.
