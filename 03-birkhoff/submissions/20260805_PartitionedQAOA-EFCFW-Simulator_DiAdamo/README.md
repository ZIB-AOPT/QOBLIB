This folder contains benchmarking results for the Birkhoff decomposition problem using a quantum-classical hybrid approach combining **Partitioned QAOA** with the **Extended Fully-Corrective Frank-Wolfe (E-FCFW)** framework, executed on quantum simulators.

## Algorithm Overview

Our approach is built upon the **Extended Fully-Corrective Frank-Wolfe (E-FCFW)** framework introduced by Pennington et al. (2025) for graph decompositions, adapted here for the Birkhoff matrix decomposition benchmark in QOBLIB.

### 1. E-FCFW Framework (Pennington et al., 2025)
The Extended Fully-Corrective Frank-Wolfe (E-FCFW) algorithm iteratively decomposes a target matrix $M$ into a weighted combination of matching/permutation matrices:
1. **Matching Sampling**: In each iteration $k$, a set of candidate sub-matchings is generated by a sampling subroutine (such as QAOA) operating on the current residual matrix $M_{\text{res}} = M - X_k$.
2. **Weight Optimization & Pruning**: Weights for all accumulated candidate matchings are optimized (via convex quadratic optimization), discarding zero-weight matchings to maintain a sparse representation.

### 2. Novel Contribution: Graph Partitioning (Partitioned QAOA)
To scale QAOA sampling to large-scale benchmark instances ($16\times 16$, $32\times 32$, $64\times 64$, $100\times 100$) without exceeding qubit count or device connectivity constraints, we introduce **Graph Partitioning via Divi**:
* **Sub-graph Decomposition**: The residual demand matrix is mapped to a weighted bipartite graph and partitioned into smaller sub-graphs (with a maximum threshold of edges/qubits per partition, e.g. $\le 80$ edges resulting in 30–34 qubits).
* **Subgraph Characterization & Parameter Validation**: Each sub-graph partition undergoes pre-execution characterization to compute spectral energy bounds, validate penalty terms ($\lambda_{\text{safe}}$), and set initial QAOA parameters ($\beta, \gamma$), ensuring high likelihood of valid matchings upon measurement.
* **Parallel Execution**: Each partition QUBO sub-problem is compiled into a 1-layer ($p=1$) QAOA circuit and executed on the simulator.
* **Beam-Search Aggregation**: Candidate partition measurement samples are recombined into valid global matchings using a beam-search aggregation strategy.
* **Edge-Swap Local Refinement**: Local edge-swap moves are applied post-aggregation to further enhance matching weights prior to inclusion in the candidate pool.

### 3. Decomposition Output & Metadata
* **QAOA Decomposition (QOBLIB PR #34 Compliant)**: Following the relaxation of the exact integer matching constraint in QOBLIB (PR #34), this submission reports the decomposition directly achieved via **Partitioned QAOA sampling and E-FCFW weight optimization** without appending classical Hungarian completion matchings.
* **Success Threshold Metric (`1e-5`)**: `Success Threshold` is set to `1e-5` (maximum allowed normalised squared Frobenius reconstruction error $\le 10^{-5}$).

## Software & Hardware Stack

- **Divi** (Qoro Quantum): QAOA circuit construction, graph partitioning, and compilation.
- **Quantum Hardware Simulation**: All simulations were done with Maestro MPS simulation with bond dimension set to 64 via Qoro's cloud services.
- **SciPy**: Convex quadratic optimization / non-negative least squares for E-FCFW weight optimization.
- **NetworkX**: Graph representation and utilities.

## Instance Naming & Folder Structure

Each subfolder `B{N}_{NNZ}_{ID}` holds the result for one problem instance:
- `N`: Dimension of the $N \times N$ doubly stochastic matrix (e.g. 16, 32, 64, 100).
- `NNZ`: Matrix density indicator (sparse instances use $N$; dense instances use $N^2$).
- `ID`: Instance identifier (e.g., 1, 6).
