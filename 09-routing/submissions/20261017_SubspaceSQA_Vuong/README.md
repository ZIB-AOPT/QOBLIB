**Submitter:** Vuong Kha Anh Son · **Date:** 2026-10-17 · **Code:** [`vkas0812-sys/qoblib-routing-exact-sqa`](https://github.com/vkas0812-sys/qoblib-routing-exact-sqa)

All 55 `XSH-n20-k4` instances in `09-routing` benchmarked using **`SQA-Subspace`** (Subspace-Guided Simulated Quantum Annealing via Path-Integral Monte Carlo with $P = 16$ Trotter replicas across 5 independent runs of 1,000 sweeps per instance).

The algorithm directly exploits the universal zero-slack tight-capacity invariant ($\sum_{i=1}^{20} d_i = 4Q$, fleet slack $\Delta = 0$). By confining the quantum state dynamics to the feasible manifold of exact-capacity partitions ($\sum_{i \in S_r} d_i = Q$), `SQA-Subspace` bypasses the severe quadratic penalty barriers that cause standard unconstrained penalty-based QUBO/Ising annealing to fail on 0/55 instances.

## Algorithm Description

- **Representation & State Space:** The feasible state space is the discrete manifold of valid 4-vehicle partitions $\mathcal{P}_4 = \{S_1 \sqcup S_2 \sqcup S_3 \sqcup S_4 = \{1,\dots,20\} \mid \sum_{i \in S_r} d_i = Q\}$.
- **Trotter Replicas ($P = 16$):** Evolves $P = 16$ imaginary-time slices coupled along the Trotter dimension with ferromagnetic coupling:
  $$J_\perp(t) = -\frac{1}{2} T \ln \tanh\left(\frac{\Gamma(t)}{P T}\right)$$
  at effective temperature $T = 6.0$.
- **Transverse Field Schedule:** $\Gamma(t)$ annealed geometrically from $35.0 \to 0.175$ over 1,000 sweeps.
- **Quantum Tunneling Transitions:** Multi-scale 2-route, 3-route, and 4-route recombination moves that tunnel between disjoint tight-capacity partitions without leaving the feasible manifold.
- **Objective Time Series:** Monotone non-increasing incumbent traces recorded with microsecond timestamps across all 5 runs per instance in `<instance>_objective_time_series.json.gz`.
